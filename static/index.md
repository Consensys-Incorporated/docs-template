# Consensys documentation guide

A template repository and contribution guidelines for Consensys documentation sites,
built with Docusaurus and hosted on Vercel.

## What this guide covers

- [Set up a new documentation site](https://docs-template.consensys.net/create)
- [Contribute to the docs](https://docs-template.consensys.net/contribute)
- [Configure advanced features](https://docs-template.consensys.net/configure)

## Agent-readable resources

- [llms.txt](https://docs-template.consensys.net/llms.txt) lists the main documentation pages.
- [llms-full.txt](https://docs-template.consensys.net/llms-full.txt) contains the full documentation corpus in one Markdown file.
- [sitemap.xml](https://docs-template.consensys.net/sitemap.xml) lists the published site URLs.

## Questions

For questions about Consensys documentation, open an issue or discussion on
[GitHub](https://github.com/Consensys/docs-template) or ask in the
[Consensys Discord](https://discord.com/invite/consensys).
